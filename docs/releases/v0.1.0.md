# v0.1.0 — first baseline release

Release date: **26 October 2026**. Branch: `main`. Tag: `v0.1.0`.
This baseline also initializes the remote `development` branch for testing.
All later milestone work follows the [branch and release workflow](../workflow.md):
separate milestone branches, integrated and pushed to `development` on completion;
promotion to `main` requires an explicit release request.

## Included

- Browser app foundation using TypeScript, Three.js, Rapier and Vite.
- Four-wheel suspension, chassis pitch/roll, live diagrams and the tuning workbench.
- Per-wheel tyres, engine/gearing, differentials, brakes and driving assists, with
  FF, FR, MR and AWD reference cars, reverse, and keyboard/gamepad input support.
- Shared 3D road/terrain surfaces, elevation, banking, variable width and an
  authored proving circuit.
- Revised M4 seeded touring/GP circuit design, same-land alternatives, previews,
  validation, reference speed/line diagnostics and recipe export.
- M5 kerbs, mixed run-offs, escape guidance, barriers, pit/service lanes, garages,
  stands and seeded primitive scenery; per-wheel material blending, loose-surface
  drag and optional surface sound.
- Corrected map handedness and a vehicle heading arrow.
