# v0.2.0 — solo racing baseline

Release date: **26 October 2026**. Branch: `main`. Annotated tag: `v0.2.0`.

This release promotes the user-approved `development` state `c885073` through M8,
including the tyre-feedback sensitivity adjustment. Release preparation uses
`codex/release-v0.2.0`; `main` and `development` are synchronized to the released
commit. The first M0–M5 baseline remains at its original `v0.1.0` tag.

## Added since v0.1.0

- **Procedural cars:** eleven recognizable car families, FF/FR/MR/RR/AWD packaging,
  component-derived mass/inertia, dimension-aware wheels/collision and sectioned
  primitive bodies. Seeded previews check construction and physical response.
- **Tuning and comparison:** linked axle/per-wheel edits, setup history, a named
  garage, complete JSON imports/exports, repeatable A/B tests and a 120 Hz response
  recorder with freeze/scrub/overlay controls. Keyboard/gamepad settings include
  remapping, response curves and a live input meter.
- **Expanded circuits:** inherited urban/rural/mountain/airfield road networks,
  street circuits, progressively banked speedways, road/oval hybrids and 8–24 km
  endurance venues. Variants, road provenance, lane cross-sections, class/reference
  lines and streamed local render/collision residency support these larger venues.
- **Solo practice and time trials:** directional 3D timing gates, three sectors,
  interpolated timing, tyre-centre track limits, pit/wrong-way warnings and explicit
  invalidation after interruptions, resets or setup changes.
- **Personal bests and ghosts:** results keyed by track, route, car, mechanical
  tune, assists, rules and build. Non-colliding 20 Hz recorded poses support live
  deltas, adjustable visibility/opacity and validated session JSON import/export.
- **Circuit library:** name, favourite, search, rename, restore and import/export
  accepted definitions and variants. Removal uses recoverable Trash.
- **Driving presentation:** synthesized engine/tyre/impact feedback, bounded
  skid/smoke/dust pools, a bonnet camera, adjustable chase camera and quality modes.
  Rubber marks require twice their original slip power to start; ordinary partial
  slip gives 20% of the former squeal response, recovering the existing maximum
  during heavy slip. The volume control and full-slip intensity are preserved.

The earlier four-wheel semi-arcade physics, orthographic pitch/roll diagrams,
terrain-fitted touring/GP generation, mixed surfaces, red/white kerbs, run-offs,
barriers, pit facilities and primitive scenery remain included. See the
[M6](../m6.md), [M7](../m7.md) and [M8](../m8.md) guides.

## Upgrade and saved data

Package and lockfile versions are **0.2.0**. Dependency versions and runtime source
are unchanged from the approved development state. Run `npm ci` and `npm run build`
for a local production build, or `npm run dev` for the workbench.

The existing build fingerprint includes the lockfile, including package metadata.
The release version bump therefore changes the comparison fingerprint from
`3b519332fd726112` to **`3915c9277118cf78`**, without changing physics behaviour.
Earlier development bests/ghosts retain their old keys; they do not become release
personal bests, and incompatible ghost imports are rejected. This release does not
delete the old records. Garage, setup and circuit-library formats are unchanged.

Browser storage belongs to its origin, including the port. Keep the same origin
to retain local data, and export setups, circuits and compatible session references
before clearing browser storage or changing origins. Ghosts record poses; they
are not deterministic physics replays or an online leaderboard.

## Limits and future work

This baseline supports solo driving/time trials. AI racing, multiplayer, racing
bridges/tunnels, weather, damage, tyre wear, fuel strategy and career modes remain
future work. Open rally and hill-climb routes remain outside the project scope.
The committed [spatial/synthesized audio proposal](../research/audio-system.md) is
research and planning; that expanded audio system is not implemented here.

Performance measurements apply to the named Ryzen 5 5600X / 32 GiB / RTX 3060
desktop and their stated sample scope. Physical gamepad validation and broader
hardware/browser coverage remain outstanding. The build retains the existing
large Three.js/Rapier bundle warning.

Future work continues on separate `codex/` branches, integrated and pushed to
`development` for testing. Another promotion to `main` requires an explicit
release request. See the [release workflow](../workflow.md).
